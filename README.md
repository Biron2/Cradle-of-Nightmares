# Cradle of Nightmares

<img width="920" height="430" alt="Library Header Capsule 920x430" src="https://github.com/user-attachments/assets/5ebf912c-8cce-424d-ab4e-c28c4f262737" />

**A first-person horror adventure game developed with Unity.**

Cradle of Nightmares is a single-player horror adventure set in an alternative version of Russia in the 2000s. Players take on the role of Faust, an agent of a secret organization capable of traveling through time to investigate and confront notorious criminals from history.

This project was my first complete game developed with Unity, taking me through the entire development process — from initial implementation to publishing a game on Steam.

## About the Game

- First-person exploration
- Horror atmosphere and narrative-driven gameplay
- Environmental puzzles
- Time-travel mechanics
- Investigation of historical criminals
- Hidden objects and secrets

Cradle of Nightmares was my first serious experience with Unity game development.

The project represents an important milestone in my development journey, giving me hands-on experience with gameplay programming, implementing game systems, working with Unity, and preparing a game for commercial release.

The codebase reflects my early experience as a developer and is preserved as part of my development portfolio.
